# Piscineiro – Ponta Porã / Pedro Juan Caballero

Site de serviços de piscineiro para **Ponta Porã (MS)** e **Pedro Juan Caballero (PY)**.
Limpeza, manutenção e tratamento de piscinas com orçamento direto pelo WhatsApp.

## 🚀 Demo
`https://joilsoni.github.io/piscineiro` *(ativar GitHub Pages)*

## 💭 Funcionalidades
- Lista de serviços (limpeza, manutenção, sujeira grave)
- Galeria antes/depois
- Formulário de orçamento → WhatsApp
- Design dark, mobile-first, visual "água de piscina"

## 🛠 Tecnologias
HTML5 · CSS · JavaScript (jQuery) · Bootstrap 5 · Font Awesome · JSON

## 📦 Uso
1. Clone o repositório
2. Edite `assets/data.json` (serviços, preços, WhatsApp)
3. Coloque fotos WebP em `assets/fotos/`
4. Abra `index.html` no navegador

## 🌎 Hospedagem
GitHub Pages: Settings → Pages → branch `main` → `/ (root)`
